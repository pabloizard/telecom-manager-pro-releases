# TelecomManager Pro — Versiones

Este repositorio **solo publica las versiones** de TelecomManager Pro (gestión y ciberseguridad de redes: inventario con IPAM, CRM, monitor con alertas, herramientas de diagnóstico y auditoría). No contiene el código fuente.

## Descargar
Ve a [Releases](../../releases) y descarga `TelecomManager_Pro_Clean_Install.zip` de la última versión.

## Comprobación de actualizaciones
La aplicación consulta la API pública de este repositorio para avisar de nuevas versiones. Solo informa: nunca descarga ni instala nada por sí sola.
